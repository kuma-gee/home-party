# Parcel Post

**1 VR sorter (first-person) + 2 mobile couriers (top-down town map)**

- **VR physical craft:** read labels, match packages, stamp, wrap, load into the van. Precision = the skill.
- **Mobile logistics:** top-down town map — drive the route, deliver before 5pm, avoid a mild rush-hour slowdown.
- **Stakes:** delivery deadline + accuracy score. Wrong address = extra trip, lost time, lower score.
- **Info asymmetry:** VR sees package details, mobile sees the map — neither can finish alone.
- **Communication:** "that's the blue house, two lefts past the bakery — package says fragile, don't jostle."
- **Reuse:** pickables, top-down cam, pass-counter = loading dock.

**Strong info split (package vs map) + a real but gentle deadline.**
